# 固定预测上的 NMR 峰归属

本模块输入已知结构、匿名观测峰和冻结的结构位移预测，输出带证据的集合归属。它不训练模型，也不参与候选分子检索或正式检索系统的选型。

三种基线使用相同的预测中心、容量、结构映射和观测：

| 方法 | 代价与约束 |
| --- | --- |
| B0 | 各峰独立选择最近的 carrier；允许复用结构单位 |
| B1 | 最近距离代价，加全局容量排他、缺失和未解释峰 |
| B2 | 稳健混合分布代价，加成员门控、容量排他和允许的合并 |

`mapping.py` 区分核容量单位与位移分布。一个 CH₃ 可以是质量为 3 的单个单位；同一单位的多个 carrier 共享容量。未知的氢分区保留为 parent pool。完整 attachment 与联合映射约束不能拆成逐峰独立的映射选择。

`source_reference.py`、`source_transport.py` 和 `admission.py` 管理源记录、完整结构映射及准入证据。`native_adapter.py` 将固定模型接口转换为容量预测。`costs.py`、`baselines.py` 和 `solver.py` 构建并求解三个固定问题。`execution.py` 提供逐记录预算、原始字节绑定及统一执行证据核验；评价与诊断使用同一个核验入口。`metrics.py` 与 `calibration.py` 分别处理固定分母评价和验证集置信度校准。`render.py` 将已有归属及证据绘制为交互报告。

## 数据与评价边界

推理 payload 只包含匿名观测、结构侧预测及批准的数值配置。源标签、联合 gold 和质量策略留在评价侧。模型预测只计算一次；三种基线共享同一份冻结结果。

当前源相对路径使用 `source_relative_current_serialization`，参考依据是 `source_asserted_encoded_graph`，信任依据是 `internal_source_consistency`。数值相同的已知源标签形成精确 Decimal bins。这个路径需要单独报告，不能写成已核验的实验峰标注或天然重叠。

固定分母成功率包含已准入 gold 对应的超时、弃权和预测失败。条件准确率另列受支持的分母。完整输入峰集合的正确性与完整谱的正确性分别报告。缺少完整映射、求解证书或足够区间支持时，输出 unknown、弃权或 NA，并保留原身份账本。

## 本地验证

在仓库根目录安装项目已有依赖后运行：

```sh
python -B -m unittest discover -s tests/assignment -v
```

该目录的测试使用合成数据验证契约、容量、联合映射、代价、求解、执行预算、评价、校准、绘图和子进程清理。它们不运行训练或正式实验批次。

真实实验必须另行提供冻结输入、预测、准入、数值配置、完整身份账本和独立审查的精确 SHA。执行器使用原始 payload bytes，并继承外层逐记录 start/deadline；不能通过重新解析或重启局部阶段重置预算。实验外层入口及对应源文件清单随实验代码另行保存。
