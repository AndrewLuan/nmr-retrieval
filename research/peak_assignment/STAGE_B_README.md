# Frozen Stage B: portable source delta

The six B entrypoints cover control, execution contract, phase supervision, packaging, the native-test C caller, and report application. `Stage_B_source_delta.json` binds the actual deployment handoff's 14-source map to public copies; existing public cache builder, estimator, base caller and base packager are reused. Four reviewed gate/report regression modules and the additionally referenced base test module are included as source, with assertions and process-wait semantics retained. Their import/compile validation is separate from executing their full original regression suites.

The immutable native/assignment packages already in the repository supply the core; no 220-source duplicate, checkpoint, physical registry, test row or actual phase output is included. Public control SHA values differ from actual D/JJ run-source SHA values. Any new public run requires new exact public source, input, review, suite, phase and owner-once bindings. Historical reviews/receipts are provenance, not authorization for relocated code.

Every external artifact/config access remains subject to the strict existing runtime manifest, default authorization false. `portable_stage_runtime.py` captures the original explicit runtime CLI before dependent modules consume it, verifies authorization, and propagates the identical path/SHA through outer → worker → phase. Supplied child runtime arguments must match exactly. It does not mint suite/phase execution certificates or bypass the owner release, independent source/application gates, persistent once claims, exact source/schema/numeric controls, process budgets or cleanup receipt.

Stage A remains source extraction/admission. B uses reviewed actual A outputs, preserves unavailable identities and existing gold eligibility, shares frozen predictions across B0/B1/B2, and applies the existing rejected/off C validation calibration without test selection/refit. The public copies preserve raw payload/result receipt binding, independent initial denominator checks, report-axis separation, fixed 2000/173/.95 estimates, high-confidence-off and unsupported/unknown semantics.

Public, private-data-free interface check:

```sh
python -B research/peak_assignment/Stage_B_synthetic_checks.py
```

This imports public sources in a temporary CWD under Python `-I`, denies model imports, checks a dummy child's exact runtime digest and canonical argv, verifies phase subprocess runtime propagation, rejects false authorization and compiles the source inventory. It never executes a real phase, model, solver, score, calibration, or a test spectrum. Full original scientific/process regressions remain separately reviewed source and should only run with identity-free fixtures in a separately approved CI validation. Root owns CI, ignore-list changes and Git publication.
